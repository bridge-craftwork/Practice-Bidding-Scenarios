# Bookmark — coaching drift after bba-cli v2.3.2 regen (2026-07-31)

Full pipeline was re-run from `dlr` on all 345 scenarios with **bba-cli
v2.3.2** (the `BidSystem` tag #3 fix — auctions now derived from the `.bbsa`).
Deals are **byte-identical** to before (dealer seed=5 is fixed); only the
**auction analysis** moved. This bookmark records which served coaching
lessons drifted, classified by severity, so re-curation can be triaged.
**No lessons were rebuilt in this session** (David: deliver the report,
triage later).

## How the drift was measured

- Lesson deals matched to the regenerated pool (`bba/<scn>.pbn`, or
  `bba-curated/` where present) by the **set of four hands** — rotation- and
  seat-invariant, so 180°-rotated seat-alternation boards still match. This
  removed the false "MISS = 15/30" noise a naïve `%`-hash compare produced.
- Per matched board: compare the lesson's embedded `[Auction]` (calls only,
  `AP` normalized) and, when they differ, whether the **final contract**
  changed.
- **Spiral_Raises_*** auctions are *substituted* (bba-cli cannot bid them),
  so only deal-presence is checked, not auction equality.
- Detector scripts: `scratchpad/drift3.py` (and v1/v2) — throwaway, in the
  session scratchpad, not committed.

`CONTRACT-CHG` is a **screen, not a verdict**: it flags a board for human
bridge judgment, it does not mean the lesson is wrong (see hazard below).

## The hazard — do NOT blind-rebuild

"Contract changed" hides two opposite causes:

1. **Old auction was buggy** → the v2.3.2 fix reveals correct bridge →
   adopt the new line. Likely most Basic_*/convention lessons, whose
   auctions were machine-generated by the old (buggy) bba-cli.
2. **New pool got *worse*** → re-curating from it would *destroy* a good
   lesson. Confirmed example — **Slam_after_Stayman**: the lesson teaches
   careful cue-bidding
   `1N–2C–2H–3S–4D–4S–4N–5S–6H`; the regenerated pool now **blasts**
   `1N–2C–2H–6H`. The *lesson* is the good bridge here.

So each must-fix lesson needs a one-look ruling: **adopt new / keep old /
re-curate different boards** — a bridge-judgment call (candidate for Rick on
the close ones).
