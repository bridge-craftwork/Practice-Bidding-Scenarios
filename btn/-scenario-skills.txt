# from the convention card's vocabulary (bridge-craftwork/convention-card,
# spec/conventions/<category>/<name>.toml). The manifest carries them as
# `scenarios[name].skills`, so a tool can say "PBS has deals for Bergen
# raises" (the convention card editor's Solo practice report).
#
# Format:
#   Scenario_Name: category/skill, category/skill
#   # comment
#
# A scenario names the conventions its deals practise for the side at the
# table (Opps_Weak_Two practises defending against preempts, not weak twos).
# A scenario not listed practises nothing on the list: general bidding, or
# a treatment the vocabulary doesn't have yet.
